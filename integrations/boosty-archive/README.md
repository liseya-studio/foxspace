# Архив канала Telegram → Boosty

Экспортируйте один канал в Telegram Desktop. В меню канала выберите экспорт истории, формат JSON и нужные типы медиа за весь период. Сохраняйте `result.json` рядом с папками медиа из того же экспорта.

Из этой папки репозитория можно собрать очередь без сети и без входа в Telegram:

```bash
python3 run.py import-export --export /path/to/telegram-export --folder /path/to/boosty-queue --hashtag '#работа' --replace-tag '#работа=#тег_на_boosty'
```

Посты идут от старых к новым, вложения внутри поста — по ID сообщений. Подготовленный реестр `boosty-archive.json` открывается в «Управление → Архив Boosty». Форматирование преобразуется в текст с абзацами. В параметре `--replace-tag` пустое значение удаляет тег, `--heading` добавляет строку перед текстом.

Если в экспорте нет ID альбомов, такие записи требуют проверки. Чтобы восстановить точные границы альбомов, сверяйте историю со своего аккаунта Telegram. Можно передать уже скачанный экспорт и переиспользовать вложения по ID сообщений.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py scan --channel @channel --export /path/to/telegram-export --folder /path/to/boosty-queue --hashtag '#работа' --replace-tag '#работа=#тег_на_boosty'
```

В онлайн-режиме используйте API ID и API hash своего приложения Telegram. Скрипт запросит их и выполнит вход в Terminal. Сессия лежит в `~/.foxspace-boosty`. Для разных аккаунтов можно задать отдельные пути в `FOXSPACE_TG_SESSION`.

### Очередь отправки

Свяжите свой Telegram с нужным блогом через настройки Boosty. Предпросмотр можно запустить без соединения:

```bash
.venv/bin/python run.py send --folder /path/to/boosty-queue --blog https://boosty.to/blog --tier 'Точный текст кнопки' --limit 1
```

С флагом `--apply` скрипт отправляет записи официальному `@boosty_posting_bot` по одной. Он выбирает уровень, когда бот показывает точное имя кнопки и ссылку на ожидаемый блог. Запись считается опубликованной после ссылки на пост именно в выбранном блоге. После неизвестного ответа очередь останавливается и сохраняет ожидающую запись. Если уровень или блог требуют выбора вручную, закончите текущую отправку в чате с ботом.

После проверки укажите результат:

```bash
.venv/bin/python run.py resolve --folder /path/to/boosty-queue --blog https://boosty.to/blog --post '123:45' --url 'https://boosty.to/blog/posts/UUID'
```

Флаг `--checked-not-published` вместо `--url` возвращает проверенную неопубликованную запись в очередь. Первый запуск рассчитан на пробную запись, затем задайте размер партии. Изображения, видео и аудио отправляются в исходном порядке. Неподдерживаемые типы медиа, отсутствующие файлы и посты длиннее лимита Telegram остаются для ручной подготовки.
